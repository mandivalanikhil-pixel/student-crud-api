# Student CRUD API

FastAPI Student CRUD API for DevOps Assignment 1.

## Technologies

- Python
- FastAPI
- Pydantic
- Uvicorn

## APIs

- POST /students
- GET /students
- GET /students/{id}
- PUT /students/{id}
- DELETE /students/{id}

## Run Project

```bash
pip install -r requirements.txt
uvicorn main:app --reload
